# Asset library (by asset id)

This library holds every VFX texture and mesh the user has supplied, named by what it looks like (or by its role, when the author's emitter names say it), so it works without the source place open. Sources so far:

- `Workspace.modern_vfx` (356 assets)
- `Workspace.Effects` (134 assets; entries prefixed `Effects/` in seen-in)
- `Workspace["lightning stuff"]` (191 assets; prefixed `lightning stuff/`): lightning and electric sheets, about 50 lightning decals for meshes, spike and crater meshes

Both are in PlaceId 114773467389373 and were added 2026-10-22. The machine-readable version is `assets/catalog.tsv`, and the 16-frame decal flipbooks are in `assets/decal_flipbooks.tsv`. The role guide is in `textures.md`. This file is regenerated by `tools/build_assets_md.sh`.

**Using an entry:**

- Texture: `rbxassetid://<id>`.
- Particle sheets: set `FlipbookLayout`/`FlipbookMode`/`FlipbookFramerate` from the catalog. A `Custom` layout can't be rebuilt from properties alone, so clone an emitter that already uses that id, or test it, then record the result here. With `FlipbookMode=OneShot` the sheet plays once over each particle's lifetime and the fps column doesn't matter. It only matters for Loop/PingPong/Random.
- Meshes: `mesh_native_size` is `MeshSize` (X×Y×Z). For a SpecialMesh, `Scale = desiredStuds / native`. The flat or thin axis tells you how to orient it.
- Prefixes: `pe_` particle, `beam_`/`trail_` strip textures (read along the length), `decal_` decals wrapped on meshes, `mesh_`, `meshtex_` MeshPart textures, `image_` screen-space ImageLabel.
- Names ending `_colored` have color baked into the texture, so `Color` only tints them. Everything else is white or greyscale and takes its hue from `Color`. Blood sheets, for example, are white and tinted red.
- **Never use `pe_BLOCKED_moderated_circle` (14687560696).** It's moderated and renders blank. Verify `decal_UNAVAILABLE_placeholder` (130540857336778) before using it, because its thumbnail is the unavailable placeholder.
- Not catalogued on purpose: avatar clothing, hair and face meshes, weapon (blade, hilt, guard) meshes, camera props and UI counters.
